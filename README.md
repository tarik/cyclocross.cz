# cyclocross.cz

A bilingual (Czech and English) hub for cyclocross in Czechia: a trustworthy race calendar, practical details for racers and spectators, and an original pixel-art landscape.

The project is in early development. See [SPEC.md](SPEC.md) for the specification and [AGENTS.md](AGENTS.md) for the working rules.
